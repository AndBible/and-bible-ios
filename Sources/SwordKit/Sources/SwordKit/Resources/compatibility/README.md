# Android Java character compatibility

`java-character-android37-icu78.bin` pins the BMP `char` behavior used by Android 37's
`java.lang.Character`: simple upper/lower mapping, `isLetterOrDigit`, `isDigit`,
`isWhitespace`, `isUpperCase`, and `digit`. Android 37 delegates these non-ASCII operations to ICU 78.3
(Unicode 17.0), so a macOS Swift or host OpenJDK table is not an equivalent source.

The fixed-width little-endian resource is generated by
`scripts/generate_android37_java_character_table.c` with Homebrew `icu4c@78` 78.3. Its header is
`ANDJCHAR`, ICU `78.3`, Unicode major `17`, reserved `0`, and row count `65536`; each eight-byte row
stores uppercase, lowercase-of-uppercase, direct lowercase, Java predicate flags (including ICU
`Cased`/`Case_Ignorable` for root-locale final sigma and `isUpperCase` for GBF scanning), and
radix-36 digit value for one UTF-16 unit.
